Supported storage

  • Google Drive — OAuth Desktop client + credentials.json
  • AWS S3 — Access Key / Secret / Bucket / Region
  • Cloudflare R2 — S3 API endpoint https://<ACCOUNT_ID>.r2.cloudflarestorage.com
  • Backblaze B2 — S3-compatible endpoint for your region
  • DigitalOcean Spaces — e.g. https://nyc3.digitaloceanspaces.com
  • Linode Object Storage — e.g. https://us-east-1.linodeobjects.com
  • Wasabi / MinIO / Other S3-compatible — custom endpoint + keys

Google Drive setup

  1. Open Google Cloud Console → create/select a project.
  2. Enable Google Drive API → create OAuth client (Desktop app).
  3. Upload credentials.json in the Storage tab → complete linking.
